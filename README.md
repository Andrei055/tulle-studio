# Tulle Studio

Рабочий первый vertical slice параметрического редактора конвертов PLA + ткань. Next.js / React / TypeScript, Zustand, Clipper, Three.js. Вычисления и файлы проекта остаются в браузере.

```sh
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

Открыть адрес из вывода `npm run dev` (по умолчанию http://127.0.0.1:3000). Production — статическая папка `out/`; её можно разместить на любом static hosting. Node 20.9+.

## Рабочий сценарий

1. В «Форма» задайте ширину/высоту закрытого конверта, клапан, карман, контур и зоны гибкости. Числовые поля применяются по Enter или при потере фокуса.
2. Во вкладке «Орнаменты» выберите вектор. Shift+click добавляет к выделению. На холсте работают drag, масштабирование угловым маркером, вращение круглым маркером; справа точные числовые свойства, центры/края, зеркала и копии.
3. Для осей выберите область центрирования. Привязка работает к сетке и центрам. Стрелки сдвигают на 1 мм, Shift+стрелки на 10 мм. Колесо меняет масштаб, инструмент ладони переносит холст. Undo: Cmd/Ctrl+Z; Redo: Shift+Cmd/Ctrl+Z; Delete удаляет незаблокированное выделение.
4. «Слои»: управление видимостью и блокировка орнаментов. Скрытая рамка/орнаменты исключаются из производства; видимость ткани и PLA относится к preview.
5. «Печать»: нижние/верхние слои, ткань, сопло и расчёт Z. «3D модель»: вращение, zoom, разнесённые слои.
6. «Сохранить»: редактируемый project JSON v1; папка в шапке загружает его. «Референс» встраивает локальное изображение в JSON.
7. «Экспорт»: manufacturing SVG, проверенный binary STL и отдельный JSON профиля. SVG для обоих слоёв экспортируется отдельными файлами выбором нижнего/верхнего слоя. STL не содержит ткани, guides, паузы или G-code.

## Что подтверждено и что пока предполагается

Фото подтверждают сетку и декоративный PLA, но не размеры/топологию соединений. Реализована явно описанная развёртка: клапан → спинка → подгибаемый карман. Ширина и высота изделия отличаются от размера печатной развёртки. Механика, скрепление боковин, адгезия, допуски ткани и профили принтеров требуют физического купона. Это не готовый Bambu профиль и не автоматический слайсер.

Не входят: 3MF, AI генерация, AI восстановление по фото, пользовательский SVG import, live symmetry, группы, distribution/equal spacing, скругление углов отдельным параметром и симуляция сложенного изделия. Эти этапы описаны в плане, без неработающих UI-заглушек.
