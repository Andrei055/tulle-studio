# Tulle Studio

Редактор кружевных конвертов PLA + ткань. Пять частей: прямоугольное основание и четыре лепестка с тканевыми сгибами. 20 готовых векторных полотен: 10 простых и 10 плотных. Надпись на основании конверта праздничным шрифтом Great Vibes с кириллицей.

```sh
npm install
npm run dev
npm test
npm run typecheck
npm run build
```

Node 20.9+. Production — статическая папка `out/`. Next.js / React / TypeScript, Zustand, Clipper, Three.js и локальное WASM-ядро Manifold. Файлы проекта и вычисления остаются в браузере.

## Как пользоваться

1. «Дизайн»: выберите готовый рисунок. Он сразу заполняет все пять частей. Сборка из маленьких форм удалена.
2. Потяните рисунок на конверте — всё полотно переместится. Справа доступны масштаб, поворот, зеркала и центрирование.
3. «Надпись»: текст до трёх строк, размер, положение, поворот и утолщение. По умолчанию — «С любовью» по центру основания; есть кнопка восстановления эталонного размещения. Текст входит в SVG/STL, орнамент освобождает под него место.
4. «Конверт»: размеры основания, глубины четырёх клапанов, форма/волнистость края, положение развёртки на столе. Размер основания отличается от габаритов всей развёртки.
5. «3D и складывание»: вращение камеры, последовательное складывание четырёх клапанов, разнесение PLA-слоёв в плоском состоянии. Механика ткани показана схематически.
6. «Печать»: нижние/верхние слои, сопло, ткань, расчёт Z. «Экспорт»: SVG, проверенный бинарный STL, отдельный профиль JSON. STL всегда плоский, без ткани, пауз и G-code.
7. «Сохранить»: редактируемый проект JSON v2. Файлы старой трёхсекционной конструкции v1 не преобразуются молча: при открытии показывается пояснение.

Колесо — масштаб холста; ладонь — панорамирование. Стрелки — сдвиг рисунка на 1 мм, Shift+стрелки — 10 мм. Undo: Cmd/Ctrl+Z; Redo: Shift+Cmd/Ctrl+Z. Числовые поля применяются по Enter или при потере фокуса.

## Производственные ограничения

SVG и STL используют единый контур с внутренним допуском 0,005 мм для устранения точечных касаний; допуск упрощения mesh — 0,001 мм. Проверка замкнутости выполняется при каждом STL-экспорте. Проверка не подтверждает печатаемость всех тонких элементов: физический купон нужен для адгезии, сетки и сгибов. Симуляция не рассчитывает столкновения и деформацию ткани. Настройки паузы добавляются в слайсере.

AI-генерация, загрузка SVG и 3MF пока не реализованы. Готовые рисунки генерируются воспроизводимым `scripts/generate-designs.mjs`, лицензия CC0-1.0. Референсные фотографии не распространяются в приложении.
