# Готовые композиции v2

Пользователь выбирает цельный готовый орнамент, а не создаёт его из примитивов. В UI три законченных master sheets: «Венское кружево» (розетки, пейсли, сетка), «Садовые розы» (розы/ветви), «Павлинье перо» (перья/прожилки). Каждое полотно можно двигать, масштабировать, поворачивать и зеркалить целиком.

Исходные авторские векторные композиции воспроизводимо собираются `scripts/generate-designs.mjs` в `src/library/designs.json`. Это замкнутые производственные контуры с отверстиями, а не картинки. Производные SVG в `public/designs/` показывают **эту же геометрию**, только с фоном для читаемого превью. При генерации выполняется union обводок; фоновая сетка освобождает места вокруг основного рисунка.

Asset: id, name, category, description, tags, viewBox, paths, preview, license, revision, minFeature. Добавление готового дизайна: новая запись JSON и SVG preview, код редактора не меняется. Реестр assets показывает только полные композиции. Старые шесть примитивов сохранены во внутренних ресурсах для регрессионных математических тестов, но **удалены из пользовательской библиотеки**.

Один выбранный дизайн создаёт один независимый Instance; новый дизайн заменяет полотно целиком (операция отменяема). Внутренняя схема instances сохранена для дальнейшего расширения. Видимая крупность контролируется единым процентом, что исключает случайное искажение пропорций.

Лицензия собственных композиций CC0-1.0. Орнамент с фотографии не копировался и не выдаётся за точно восстановленный. Готовые SVG поставляются вместе с приложением; сеть/AI для выбора рисунка не нужны.

## Каталог из 20 рисунков

Две группы по 10: simple — редкие розы, цветы, ветви и листья на открытом тюле; dense — более плотные букеты, лиственные венки и растительные завитки. Доля считается по площади векторного раппорта, без рамки/надписи; это не процент физических ячеек тюля. Плотные листы не используют фоновую диагональную сетку: плотность создают только сами ботанические контуры.

В JSON хранится один периодический раппорт (`repeatStep`), а `assetById` раскрывает его в полотно и кеширует результат. Превью показывает тот же раппорт. Это уменьшает размер каталога; редактируется всё полотно, без набора примитивов. Все мотивы — собственные процедурные векторные контуры; каталог Cults/Praskovia111 использован только как ориентир для направления: цветочные конверты, ветви, орхидеи, розы и текучая растительная линия.
