# Библиотека орнаментов

Каталог src/library/assets.json — массив metadata + настоящие замкнутые polygons в локальных единицах мм; public/ornaments/*.svg — соответствующие SVG previews. Формат первого среза намеренно ограничен плоскими заполненными контурами, поэтому не зависит от DOM SVG parser и одинаково работает в тестах/браузере. Никаких raster-to-mesh или CSS-scale экспортов.

Asset: id (stable), name, category, tags[], viewBox, paths (outer + holes, согласованная ориентация), preview URL, license, revision. Встроенные собственные временные assets: цветок, лист, ветвь, ромб, угол, бордюр. Источник геометрии для preview и производства один. При добавлении: добавить запись в JSON и сгенерировать SVG; код редактора не изменяется. Обязательны конечные координаты, замкнутые непустые кольца, ограничение числа точек и уникальный id. SVG с внешними ресурсами/скриптами не используется. Будущий SVG importer должен нормализовать transforms, разворачивать stroke, flatten curves и валидировать holes.

Instance не изменяет asset: position, scale, rotation, flips, visibility, lock и флаги двух PLA слоёв хранятся отдельно. Категории/теги и текстовый поиск работают по metadata. Избранное — предпочтение браузера. Предпросмотр — векторный SVG из paths. Шаблоны создают instances через те же функции центровки и отражения; координаты рассчитываются из W/H/F/P.

Расширение каталога: roses, lace, wedding, peacock, frames, central, borders, geometry, minimal, classic/luxury. Эти категории — план, а не обещание наличия художественно законченных assets в тестовом каталоге.
