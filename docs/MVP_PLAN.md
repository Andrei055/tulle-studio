# План после уточнения конструкции

## Выполняется в v2
- Основание + четыре параметрических клапана с отдельными рамками и четырьмя свободными сгибами.
- Поворот всей развёртки на печатном столе, независимые размеры клапанов.
- Готовые цельные векторные полотна: кружево, розы, павлиньи перья. Удаление DIY-примитивов из UI.
- Перемещение рисунка целиком, масштаб/поворот/зеркала, точный центр.
- 3D-схема складывания четырёх клапанов, сохранение плоского STL-экспорта.
- Новые проверки пяти панелей, шарниров, складывания, плотных векторных полотен, сериализации v2.

## Следующая физическая проверка
Сопоставить размеры с реальным изделием; напечатать купон узора и шарнира; подобрать толщину ткани/пластика и нахлёст. При необходимости добавить способ фиксации верхнего клапана. Принятые размеры сейчас настраиваемые, а не измеренные по фотографии.

## Затем
Больше художественно подготовленных SVG коллекций, проверенный импорт SVG, фильтрация локально тонких фрагментов, printer presets и исследование настоящих Bambu 3MF. AI DesignSpec и image-to-design остаются отдельными будущими этапами.
