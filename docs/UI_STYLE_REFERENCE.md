# Визуальный референс

Источник: https://printesso.ru/ — просмотрен 17.09.2026 в браузере, включая главную и #custom. Доступен. MakerWorld не прочитан.

Наблюдения: широкий округлый розовый навбар; крупная контрастная serif-типографика и курсив в заголовке; светлый молочный фон; большие скруглённые блоки; предметная фотография в круге; спокойные sans-serif подписи. В конфигураторе крупные карточки типа изделия, вкладки «Форма / Паттерн / Цвета», ряд векторных силуэтов, отдельное поле preview. Розовый и оливковый акценты, выделение выбранной карточки контуром. Иерархия строится на размере/пространстве, а не множестве теней. Анимационные детали и полный набор hover-состояний не установлены и не выдаются за измеренные.

Перенос: собственный бренд Tulle Studio, компактный serif title, розовая primary-кнопка, тёмно-сливовый текст, мягкие большие панели, зелёный акцент технологических зон. Главная сразу редактор: параметры слева, большое поле по центру, свойства справа. CAD-сетка и линейки остаются нейтральными, изделие доминирует. Реальный векторный орнамент в карточках, без копирования чужих фото/текстов/логотипа. Hover/focus 150ms, respects reduced-motion, labels и доступные названия. В узком окне панели перестраиваются; никаких декоративных неработающих кнопок.

## Изменение v2 по обратной связи
Убрана композиция из мелких форм. Каталог открывается первым, карточки показывают крупный участок настоящего готового полотна. Главный холст показывает сложную кружевную развёртку с центральным основанием по диагонали и четырьмя лепестками. Панель справа управляет всем рисунком; основной жест — drag полотна. Крупные изображения в карточках являются SVG-превью тех же векторных данных, а не отдельной иллюстрацией, обещающей несуществующее качество экспорта.
