# Геометрия v2: основание и четыре клапана

Исправление по уточнению пользователя 17.09.2026. Трёхсекционная гипотеза v1 была неверна. Модель v2 содержит ровно пять частей: прямоугольное основание, верхний, нижний, левый и правый клапаны. Четыре сгиба проходят по четырём рёбрам основания.

## Параметры и координаты

Все длины в мм. width/height — размеры основания и закрытого конверта. flapHeight — глубина верхнего клапана; bottomFlapDepth — нижнего; sideFlapDepth — обоих боковых. layoutRotation поворачивает всю развёртку на столе (по умолчанию 45°, поэтому основание видно по диагонали, как на предоставленном фото). Форма клапанов triangle / round / straight (трапеция), край straight / wave. Амплитуда, число волн, фаза и плотность остаются параметрическими.

Сначала строятся пять полигонов в системе с центром основания (0,0), X вправо/Y вниз. После layoutRotation они сдвигаются так, чтобы левый верхний угол общего bbox стал (0,0). Размер на столе — bbox объединения частей; он **не равен** width/height. SVG получает именно габарит развёртки в мм.

## Шарниры и рамки

Каждый клапан прикреплён к своему ребру основания. Fold keep-out — полоса foldWidth вокруг отрезка этого ребра, с расширением на концах. В ней нет ни орнамента, ни рамки. Ткань остаётся непрерывной. Каждая из пяти частей получает собственную рамку: solid = panel − keepOut; border = solid − inwardOffset(solid, borderWidth). Allowed = union(inwardOffset(panel.solid, borderWidth + edgeClearance)). Дополнительный closingWidth освобождает маленькую область на кончике верхнего клапана; по умолчанию 0.

## Цельный рисунок

Готовое векторное полотно — один Instance. Оно преобразуется целиком: translation, uniform scale, rotation, flips. Manufacturing pattern = intersection(transformed sheet, allowed). Прямое перемещение на холсте не требует выбора/сборки маленьких объектов. В процессе drag SVG отображает преобразованный вектор через тот же allowed clip; на отпускании сохраняются реальные координаты и заново вычисляются производственные полигоны. Один drag — одна операция undo.

Центровка относительно centroid основания. Smart snapping к его двум осям и сетке. Геометрические функции отдельных экземпляров и зеркал сохраняются для внутреннего использования, но DIY каталог не выводится.

## Складывание

3D строится из тех же пяти частей. Клапаны вращаются вокруг собственных рёбер: сначала боковые, затем нижний, затем верхний. В конце они оказываются над основанием. Толщина стопки отображается схематически; расчёта деформации ткани, соударений, защёлки и нагрузок нет. Положение «сложено» не меняет экспорт: STL всегда остаётся плоской печатной развёрткой.

При пользовательских чрезмерно глубоких клапанах возможно выступание за основание; это нужно проверять в 3D и на образце. Размеры и нахлёст фотографии не измерены. Значения по умолчанию подобраны для складывания в пределах основания, а не извлечены из снимка.
