# Геометрическая модель

## Координаты и развёртка
Миллиметры; начало (0,0) слева сверху; X вправо, Y вниз. W — ширина закрытого изделия; H — высота спинки; F — клапан; P — глубина кармана. Печатная развёртка W × (F+H+P). Клапан y=[0,F], спинка [F,F+H], карман [F+H,F+H+P]. Сгибы на F и F+H. Это явная проверяемая гипотеза конструкции, не восстановленная модель фотографий. Боковые края после подгиба требуют отдельного способа скрепления.

Клапан: прямой, треугольный или округлый профиль. Contour strategy: straight/wave, позже scallop/lace/zigzag/imported. Волна идёт внутрь заданного bounding box; amplitude, cycles, phase, samplesPerWave задаются явно. Вершины остаются на габаритах; плотность влияет на аппроксимацию, а не на единицы. Скошенные стороны треугольного клапана используют тот же генератор кромки.

## Polygon kernel
Замкнутые кольца Clipper, scale=1000. NonZero fill, положительная ориентация наружных колец, отрицательная отверстий. PolyTree восстанавливает outer/holes для экструзии. Рамка = outer − offset(outer,-borderWidth); ширина измеряется по нормали. Геометрическая точность кривых ограничена дискретизацией и округлением 0.001 мм.

KeepOut = две полосы сгиба полной ширины + полоса около свободного края кармана (closingWidth). Рамка и весь PLA вычитают KeepOut. Allowed = offset(outer,-borderWidth-edgeClearance) − KeepOut. Каждый ornament = intersection(transform(asset), Allowed); в mesh никогда не попадает исходный необрезанный SVG. Bottom и top имеют независимые include-флаги экземпляров, но одинаковые ограничения. Ткань одна непрерывная подложка по внешней границе.

## Объекты и трансформации
Instance: id, assetId, x/y, scaleX/Y (положительные), rotation degrees, flipX/Y, locked, visible, bottom/top. Asset центрируется по собственному bbox; затем scale → flip → rotation → translation. Реальная ширина/высота измеряется по преобразованному bbox. Объект вне allowed сохраняется редактируемым, но его запрещённая часть отсутствует в производстве.

## Центры, симметрия, привязки
Центр области вычисляется area-weighted polygon centroid с вычитанием отверстий; центры flap/back/pocket — centroid пересечения с соответствующим диапазоном Y. Центр экземпляра для выравнивания — центр его преобразованного bbox (стандарт CAD), не визуальный центр кривой. Выравнивание краёв использует bbox, центрирование — centroid выбранной области. Полная область и allowed могут иметь разные центры.

Mirror horizontal отражает по вертикальной оси X=cx: x'=2cx−x, rotation'=−rotation, flipX инвертируется. Mirror vertical отражает по горизонтальной оси Y=cy: y'=2cy−y, rotation'=−rotation, flipY инвертируется. Есть отражение на месте и создание симметричной копии. Сетка в мм; сначала grid snapping, затем приоритет ближайшей оси/центра другого объекта в screen-space threshold. Guides показываются только при срабатывании. Shift+click — multi-select, drag — перенос группы, pan отдельным инструментом. История транзакций drag фиксируется один раз.

## Ограничения
Нет гарантии пригодности конкретной ткани/принтера без пробной печати. Дробные мелкие islands после clipping могут оказаться меньше сопла: preflight сообщает это, но не подменяет проверку в слайсере. Нет bend simulation, автоматических креплений, live symmetry и произвольного SVG import в MVP.
