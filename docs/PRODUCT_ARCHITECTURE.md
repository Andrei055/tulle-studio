# Tulle Studio v2

Исправление продукта по уточнению пользователя: пятичастный конверт и готовые орнаментальные полотна. Старая трёхсекционная гипотеза удалена. Первый экран — каталог законченных дизайнов, дальше положение рисунка и размеры конверта.

Project JSON v2 → проверка schema → пять параметрических 2D частей в мм → рамки/четыре keep-out → intersection цельного полотна с allowed → отдельные Bottom/Top PLA → производственная экструзия → Three.js renderer / SVG / STL.

Модули: domain (versioned schema), geometry (Clipper 2D, панели, transforms, folding pose), library (готовые векторные master sheets), state (Zustand + undo), manufacturing (толщины/mesh), export (SVG/STL/JSON), components (UI), tests (геометрические инварианты). React и Three meshes не являются источником истины.

2D рисунок плавно перемещается в SVG; булева производственная геометрия пересчитывается на завершении drag, без изменения разрешённой области. 3D folding — отдельная матрица позы для каждой панели, не модифицирующая экспорт.

Next.js static export, React/TypeScript, Zustand, Clipper, Three.js. Пользовательские файлы не отправляются на сервер. Собственные готовые полные орнаменты поставляются локальными assets. Файлы v1 отклоняются с понятным объяснением, без молчаливого изменения ранее сохранённой геометрии или потери данных.

Ограничения: нет AI генерации, 3MF/G-code, трассировки картинки, физической симуляции ткани. Открытый конверт печатается на ткани с четырьмя гибкими шарнирами; качество складывания и нахлёст требуют пробы. MakerWorld ранее был недоступен, характеристики его модели не приписываются приложению.
