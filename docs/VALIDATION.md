# Проверка первого среза

17.09.2026.

- 35 автоматических проверок: размеры прямого и волнистого контура, 3 формы клапана × 2 контура × 3 фазы, постоянная ширина прямой рамки, исключение keep-out из обоих PLA, clipping орнаментов, центр тяжести несимметричной области, зеркала повёрнутого несимметричного объекта, snapping, rebuild, independent bottom/top, JSON round-trip и invalid input, mm SVG, binary STL, Z расчёт.
- Mesh: для 3 композиций и вариаций контура проверены количество инцидентных граней каждого ребра, нулевые/нечисловые треугольники и объём. Экспорт выполняет проверку текущего mesh, а не только тестового fixture.
- `npm run build` и TypeScript: успешны. `npm audit`: 0 известных уязвимостей после обновления Next.js и Vitest.
- Browser smoke: изменение ширины 180→200 обновляет размеры развёртки; вставка ветви; центрирование по Y; изменение X и угла; зеркальная копия X=60→120 и rotation=25→−25 при оси X=90; 3D и разнесение слоёв; STL экспорт с подтверждением в UI.
- Проверены мобильная компоновка и desktop 1440 px; боковые панели на desktop прокручиваются отдельно.

Это проверки геометрии и программы, не физическая валидация изделия. Нужны реальные измерения и тестовая печать для адгезии, зазоров, сгибов и крепления кармана. Проверка STL не является анализом толщины всех деталей: preflight тонких фрагментов пока использует bbox и может пропускать локально узкие участки.
